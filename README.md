# Fragmentos de la Confluencia

Compendio digital y archivo de consulta para el lore, las crónicas y la ambientación de **Confluencia**, un sistema y juego de rol de mesa actualmente en creación.

---

## Sobre el proyecto

Este sitio web recopila los relatos, la cosmología, los diferentes planos de la existencia y los registros que conforman este universo de fantasía. Funciona como una base de conocimiento interconectada para explorar libremente los mitos y secretos del mundo.

Desarrollado con [Astro](https://astro.build/).
